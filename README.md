# Diagram Dashboard

A simple React dashboard that allows users to upload a diagram image and view a list of detected circuit components.

## Features

- Upload diagram image (PNG/JPG)
- Preview uploaded diagram
- Display uploaded file name
- Replace uploaded image
- Zoom In / Zoom Out / Reset view
- Component list sidebar
- Highlight selected component on diagram
- Responsive layout

## Tech Stack

- React (Functional Components)
- React Hooks (useState, useEffect)
- CSS / Tailwind
- Mock API data
